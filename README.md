
# Trabalho de Estruturas de Dados — Tabela Hash


- Configuração: 117
- Estrutura: E1.2 — Vetor dinâmico
- Função Hash: H3 — Meio do quadrado
- Tratamento de colisões: C4 — Hash duplo
- Aplicação: A1 — Cadastro de estudantes
- Linguagem: C

# Objetivo

Implementar uma tabela hash própria para realizar o cadastro
de estudantes, utilizando vetor dinâmico, função hash do meio
do quadrado e tratamento de colisões por hash duplo.

# Funcionalidades previstas

- Inserção de estudantes;
- Busca por matrícula;
- Atualização de dados;
- Remoção de estudantes;
- Listagem dos estudantes;
- Exibição da estrutura interna da tabela;
- Redimensionamento e rehashing.

# Estrutura do projeto

- `src/`: código-fonte;
- `tests/`: testes de correção;
- `benchmark/`: experimentos de desempenho;
- `docs/`: documentação e decisões técnicas.
